# Contributing

Keep README.md, docs/, fpga/{src,build,report}/, host/{model,app,deploy}/, metrics/{logs,scripts,evidence}/, skill/ and report/.

Keep the beamforming and recognition source lists, protocols and bitstreams separate. Do not claim new board, timing or accuracy results without matching execution evidence. Do not commit local network backups, credentials, raw COS collections, environment binaries or manufacturer manuals.

Contributions to project-authored code are submitted under the repository AGPL-3.0 licence; preserve all third-party notices.
