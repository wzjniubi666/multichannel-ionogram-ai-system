# 可复用工程整理与验证流程

本文件是项目工作流说明，不冒充已安装的Codex技能。

1. 确定主线：读取最新交接与实际源码，锁定器件、顶层、通道掩码、周期数、协议和bit/DCP身份。
2. 按README/docs/fpga/host/metrics/skill/report组织文件；RTL、约束和历史证据逐字节复制，不在归档中改算法。
3. 区分当前源码、已通过实现快照、历史32周期、软件模拟与实板。保留旧时间戳与原状态，用新说明解释后续状态。
4. 用真实码表、实际捕获文件参数和有符号定点语义生成接口文档。缺失神经网络、XSA/HWH、标定或测量时明确缺失，不生成伪证据。
5. 每个指标关联原始报告路径；时序只对匹配DCP有效，不把软件模拟或独立色标亮度当硬件增益。
6. 对复制文件计算SHA256及来源清单。运行 `python metrics/scripts/verify_package.py`，保留日志/JSON。该入口不操作硬件。
7. 若更改RTL或约束，创建新版本并重新验证功能、CDC、约束覆盖、布局布线和45/50/55%占空比；旧bit的通过状态不能自动继承。

建议交付审阅顺序：根README→三份docs→MODEL.md→design_report.md→metrics.csv→来源/完整性清单→已有实板与时序证据。
