# 硬件、接线与供电

## 组成和边界

硬件是PZ-K7325T-FH开发板/核心板，器件XC7K325T-2FFG900I，板载RTL8211系列以太网PHY。PC通过已知正常网线直连板上千兆网口，JTAG用于Vivado管理。接收天线/采集设备位于上游，当前工程从磁盘M序列COS回放，不提供外部ADC采集、传感器驱动、执行器或射频发射电路。

已有用户说明为通道07、15未接天线，其余通道已同步和校准；因此保留原16槽位及编号，以0x7F7F排除两路。阵列处理模型为L形8+8、10m间距，其余14阵元保留原坐标。现场两臂地理朝向、通道到物理位置映射及IQ相位符号仍应结合实物核对，不能把113°/35°处理指向直接当作每个时段真实DOA。

## 供电与操作顺序

本包收录原厂开发板/核心板原理图、核心板手册和引脚表，见 `hardware_reference/`。供电使用与实际板卡版本匹配的原厂电源和供电接口，按随包手册确认额定输入及极性。本次未独立核对实物适配器铭牌，不虚构输入电压/电流值。FPGA内部电源由板上稳压电路产生，用户IO约束的LVCMOS33是信号电平，不是板卡外部供电值。

1. 核对板号、器件、跳线、适配器及JTAG连接，断电时检查接线。
2. 按手册上电，确认200MHz差分时钟与复位正常。
3. 需要实板操作时，在Vivado核对目标器件与本包bit身份；生产入口见 `../../host/deploy/README.md`。
4. PC与板卡网口直连，确认千兆链路；生产脚本保存并恢复原网卡配置。
5. 先跑已冻结9点验收，再进行完整扫描；保留原包、控制台与恢复日志。

本次整理未执行JTAG下载、Flash写入、网卡配置或发包。

## 顶层管脚

下表直接依据 `fpga/src/release_constraints/kt325t_network_board.xdc`。不要将旧 `kt325t_base_template.xdc` 或抽象板壳XDC混用。

| 信号 | 管脚 | 约束/功能 |
|---|---|---|
| sys_clk_p / sys_clk_n | AG10 / AH10 | LVDS，200MHz |
| sys_rstn | T26 | LVCMOS33，低有效复位 |
| rgmii_rxc | U27 | 125MHz接收时钟 |
| rgmii_rx_ctl | W26 | RX_CTL |
| rgmii_rxd[0..3] | V27 / V29 / V30 / V25 | RX数据 |
| rgmii_txc | U28 | TX转发时钟 |
| rgmii_tx_ctl | V26 | TX_CTL |
| rgmii_txd[0..3] | T25 / U25 / U29 / U30 | TX数据 |
| phy_mdc / phy_mdio | V19 / V20 | MDIO管理，MDIO双向 |
| phy_reset_n | W23 | PHY低有效复位 |
| led[0..4] | U24 / V24 / W21 / W22 / W19 | 核心板LED，高有效 |

除差分系统时钟外，上述网络/管理/LED信号采用LVCMOS33。管脚映射属于板内已连接网络，不是要求用户用杜邦线外接RGMII。

## PHY、时钟与指示灯

历史资料标识PHY地址001，管理器读取ID并配置/回读TX/RX延迟。原理图中PHYRSTB串联R152有NC标记，实际装配连通性需核对。PCB相对走线偏差±0.25ns是原约束的建模假设，未由本次整理测量验证。

LED1..5依次表示PHY复位释放、配置完成、千兆链路、核心忙、故障。正常收发前应满足配置/链路就绪。RGMII时钟域与200MHz核心域不同，使用原CDC和复位逻辑；不要用一条宽泛false_path代替跨域传输验证。
