# 本地通信配置

公开源码使用文档示例地址与示例MAC，原通信地址已替换。示例值不代表已验证的现场配置。运行前在专用板卡链路上配置自己的PC和FPGA地址，并同步修改上位机、部署脚本、RTL网络顶层参数及仿真向量。UDP端口是协议定义；如需修改，也必须同步PC与RTL。

1. 在本地副本搜索 `192.0.2.1`（FPGA）和 `192.0.2.2`（PC），设置为自己的链路地址。
2. RTL中的32位示例分别是 `32'hc0000201`、`32'hc0000202`；字节拼接形式也须一致。网络顶层参数包括BOARD_IP、PEER_IP或DES_IP。
3. 示例MAC为02:00:00:00:00:01 / 02:00:00:00:00:02；PC物理网卡MAC由本地配置提供，不得把个人网卡备份提交到仓库。
4. 按两阶段各自工具版本重新构建并验证bit。公开版不附带原bit/LTX，以免传播其中固化的网络配置。数值夹具是算法回放证据，不等于修改网络参数后的硬件验证。
5. 仿真收发两侧和上位机必须采用相同参数。原发布门禁仍需对本地构建重新生成校验信息。

原工程和bit仅保留在本地交付目录，不受公开副本修改影响。Vivado示例安装目录获准保留，部署时按实际安装位置修改。
