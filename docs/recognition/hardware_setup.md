# 板卡接线和供电

1. 板卡为璞致 PZ-K7325T-FH，芯片 XC7K325T-2FFG900I。使用开发板原配、符合厂商要求的电源。
2. 笔记本有线网口直连开发板以太网口；连接 JTAG 下载器。当前无需 SD 卡或 HDMI。
3. 上电后打开界面，点击“连接 / 初始化板卡”，或直接添加图片触发初始化。
4. Vivado 能识别 xc7k325t；程序将下载已验证的 .bit 并通过 MDIO 协商千兆。
5. 网卡默认需要 192.0.2.2/24，端口1234不能被其他同类程序占用。请先结束同项目其他识别任务。
6. 等待界面识别完成，或停止任务并等待进度停止后，可关闭板卡电源；不要在编程或计算进行中断电。
7. 本项目仅下载易失配置，不烧写 Flash；重新上电后要重新初始化。

供电电压、跳帽和下载器方向以对应板卡原厂手册为准；包内没有附带完整厂商教程。
故障时检查供电、JTAG、网卡地址和 Vivado 路径，查看 metrics/logs/ 与本次 metrics/runs/gui/ 内 worker.log。
