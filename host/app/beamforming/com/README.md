# FPGA波束合成桌面上位机（交付包版）

从原工程 `com` 导入EXE启动器、原生Tk界面、通信后台、网卡会话、运行库与原验证记录。已适配工作区路径，并于2026-11-03修复进度转发、加入已核验数据的实时预览。封印的生产协议/算法/FPGA文件保持原样。原部署文件在 `../../deploy/original_gui/`，实时修复前快照在项目 `metrics/logs/live_progress_fix/baseline/`。

## 实时版更新（2026-11-03）

传输时进度、收发统计持续更新，图约每秒逐步出现；窗口标题带“实时版”。只有完整核验且写入SQLite的点才上图，未完成位置保持灰色。继续未完成任务时先恢复已核验像素，再接着扫描。最后才生成完整NPZ、CSV和导出图片。

关闭旧窗口后重新双击本目录FPGAHost.exe即可，不需要重新烧录bit。已停止的原结果可直接用“继续任务”，无需重新处理已保存位置。新图形链路已通过离线验证，未由代理发起真实网卡修改或FPGA传输。

## 启动

在当前工作区中直接双击本目录 **FPGAHost.exe**，或者双击 `../../deploy/启动上位机.vbs`。EXE会请求管理员权限，界面仍需明确勾选已下载14路镜像并直连，点击开始合成才进入硬件流程。

程序优先读取同目录 `workspace.path`，未配置时向父目录寻找包含 `XCK325Tboshuhecheng`、`.venv-cos` 和 `HFceshi` 的原工作区。此包放在 `.` 下时自动找到。移动到别处后，先运行：

```powershell
& ./host/deploy/configure_desktop.ps1 -WorkspaceRoot '.'
```

上位机使用原工作区已封印的生产模块、计划、参考码、Python环境和数据。本包没有复制虚拟环境及完整原始数据，不能当成脱离原工作区的独立安装版。`workspace.path`仅配置路径，不改生产发布封印。

## 操作

1. 选择同一时刻完整16路COS的文件夹，或一次选择00～15全部文件；选择结果保存位置。
2. 首次使用勾选“快速验收”，先跑9点；完整扫描为41频点×118延迟=4838位置，每位置512周期。
3. 可先点击“离线自测”，结果明确为emulator，不建立网络socket或修改网卡。也可“打开历史结果”查看已有实板图。
4. 实板模式先在Vivado下载原已验证ACTIVE14 bit、确认直连，再勾选对应确认框并开始。程序进行计划/镜像预检，然后复用原网卡备份与恢复流程。
5. 查看已核验位置、进度、收发包数和UDP应用字节。100%后等待绘图、保存和网络恢复，最后以“完成”状态判断结束。
6. “停止并保存”在当前帧完成后协作停止；“继续未完成任务”只补未完成位置。错误不自动重试，先排除原因再明确继续。
7. 图表可切换MVDR、单通道00、共同背景对照、独立背景结构对照，支持缩放和保存PNG/PDF。

参数固定为16槽位、14有效（07/15关闭）、113°/35°、512周期、BFM1 v2。没有在界面加入未经验证的参数切换或自动识别算法。
