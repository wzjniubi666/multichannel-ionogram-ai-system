# 证据说明

`active14_smoke_plan`是实际11:00数据准备的9位置512周期IQ/权值/输出参考，可独立做数值离线重算。它不等同于4838点的全部原始输入。

`release`是原验收记录。`hardware_20261028`和`hardware_20261029`为两次用户实板扫描的摘要、NPZ、功率CSV和图，每批4838/4838。`hardware_*_blue_comparison_v1`为这些实板产品和同批单通道离线积累的绘图对照；“单通道”不能误标为另一套FPGA波束结果。

`legacy_sim_vectors`为旧32周期单元回归参考向量，单独标识，不用来声称512主线通过。原日志位于 `../logs`。没有收录AI生成的效果示意图。

原始完整SQLite包数据库、逐周期CSV及COS留在原工作区，见 `../../report/external_artifacts.json`。本包图表可查看/数值分析，但若要重新进行全部原包审计，须使用这些外部文件。
